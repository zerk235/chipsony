# ROADMAP — «Чипсоны» к релизу

Статус: прототип (афиша в коде, оплата имитация). Фронт уже на VK-хостинге, работает 24/7.

## v1 — MVP (регистрация на событие)
1. [ ] **Бэкенд + Supabase** — схема `supabase/schema.sql`, выгрузка афиши из БД, сохранение регистраций
   - готово, когда: фронт читает события из API; регистрация сохраняется в БД
2. [ ] **Регистрация вместо оплаты** — «Зарегистрироваться» вместо «Оплатить», без платёжных интеграций
   - готово, когда: после регистрации появляется QR-билет
3. [ ] **QR-билет + «Мои билеты»** — генерация QR, экран билета, привязка к VK ID
   - готово, когда: закрыл приложение/перезашёл — билеты на месте
4. [ ] **Дизайн** — тёмная тема, обработка ошибок сети, загрузка
   - готово, когда: открывается без интернета не падает; есть состояние ошибки
5. [ ] **Контент-афиша** — реальные события: тексты, цены, места, обложки
   - готово, когда: в БД лежат 3-5 настоящих событий
6. [ ] **QA** — чеклист на 3 платформах (VK Desktop, VK iOS/Android, m.vk.ru)
   - готово, когда: чеклист прогнан, баги в карточках
7. [ ] **Релиз** — описания, иконка, категория, тестовые группы в dev.vk.com
   - готово, когда: приложение в каталоге VK

## v2 — после релиза
