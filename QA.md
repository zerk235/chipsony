# QA — «Чипсоны» к релизу

Прогоняется перед релизом на трёх платформах: **VK Desktop** (vk.com), **VK iOS/Android**
(мобильное приложение), **m.vk.ru** (мобильная версия в браузере).

Пройти каждый пункт на каждой платформе. В колонке статуса: ✅ / ❌ / ⚠️ + короткий комментарий.

## Афиша и регистрация

- [ ] Приложение открывается в ленте «Приложения», нет белого экрана
- [ ] Афиша грузится из БД: 5 событий с эмодзи, градиентом и датой
- [ ] Офлайн: с выключенным интернетом открывается афиша из кэша, баннер «Нет соединения»
- [ ] Кнопка «Обновить» в баннере восстанавливает афишу из БД
- [ ] Добавление билетов, корзина, шаг «Регистрация», счётчик мест (не больше `seats`)
- [ ] После «Зарегистрироваться» появляется экран успеха с QR-кодом
- [ ] Ошибки сервера видны текстом (например «свободных мест осталось…»)

## Билеты и сканер

- [ ] «Настройки → Мои билеты» показывает оформленные регистрации с событием
- [ ] Нет билетов — заглушка «Пока нет билетов»
- [ ] «Настройки → Сканер QR»: ручной ввод кода принимает билет
- [ ] Сканер: первый скан — «Гость прибыл», повторный — «Уже отмечен»
- [ ] Несуществующий код — «билет не найден»
- [ ] Камера: открывается, QR-код считывается живым сканированием (мобильные платформы)

## Профиль

- [ ] «Настройки → Мой профиль»: имя и фото из VK
- [ ] Смена имени/телефона/города сохраняется
- [ ] Загрузка аватара (JPG/PNG/WEBP ≤ 2 МБ), обновление превью

## Оформление

- [ ] Тёмная/светлая тема: переключатель в настройках действует сразу для всех экранов
- [ ] Кнопки «Назад» работают на cart/order/settings/profile/tickets/scan
- [ ] Снакбары «Заказ оформлен», «Корзина очищена»

## Производительность и сеть

- [ ] Первый запуск быстрый, нет длинного белого экрана
- [ ] Медленный интернет: экран не «подвисает» без обратной связи (есть спиннер/лоадер)
- [ ] Нет ошибок в консоли (без учёта предупреждений самого VKUI)

## Перед релизом — то, что можно только из dev.vk.com

- [ ] Иконка и обложка приложения
- [ ] Категория и описание в каталоге
- [ ] Тестовые группы (токены) переданы проверяющим
- [ ] Прод-версия поднята из `main` последним релизом (см. лог GitHub Actions)
